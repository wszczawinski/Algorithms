## Algorithms

### Array Operations
- **File**: `array.ts`
- **Concept**: Basic manipulations and operations on arrays to understand how elements are accessed and modified.

### Linear Search
- **File**: `linearSearch.ts`
- **Concept**: Traverse through an array to find a target value; simple but effective for unsorted data.

### Binary Search
- **File**: `binarySearch.ts`
- **Concept**: Efficiently search in a sorted array by repeatedly dividing the search interval in half.

### Bubble Sort
- **File**: `bubbleSort.ts`
- **Concept**: A comparison-based sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.

### Crystal Balls Problem
- **File**: `crystalBalls.ts`
- **Concept**: A problem-solving scenario involving breaking points, often used to demonstrate binary or jump search variations.

### Recursion
- **File**: `recursion.ts`
- **Concept**: Solving problems by calling a function within itself, typically with a base case to terminate recursion.

## Data Structures

### Stack
- **File**: `stack.ts`
- **Concept**: LIFO (Last In First Out) structure for managing function calls, undo operations, etc.

### Queue
- **File**: `queue.ts`
- **Concept**: FIFO (First In First Out) structure for scheduling tasks, buffering, etc.

## How to Run the Code

To run any of the provided TypeScript scripts, ensure that you have Node.js and TypeScript installed. You can run a file using `ts-node`:

```bash
npx ts-node scriptName.ts
```
