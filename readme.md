# 🧮 Algorithms

This repository is a growing collection of data structures and algorithms code, sourced from books, online courses, and personal learning projects. It serves both as a practical reference and a way to reinforce algorithmic thinking through hands-on coding.

## 📂 Contents

### GrokkingAlgorithms
Python implementations of the algorithms covered in *Grokking Algorithms* by Aditya Bhargava. Focused on clarity and conceptual understanding.

### LastAlgorithmsCourse
TypeScript exercises from The Last Algorithms Course by ThePrimeagen on Frontend Masters. Emphasis on fast-paced problem-solving patterns, hands-on implementation, and algorithmic intuition.


---

## 🚀 Running Code

- **Python scripts**: `python3 script_name.py`
- **TypeScript scripts**: `npx ts-node scriptName.ts`
